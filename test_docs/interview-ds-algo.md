## 一、常见数据结构

### Q1: 数组和链表的区别？⭐

**简答：**
> 数组连续内存、随机访问O(1)、增删O(n)；链表非连续、随机访问O(n)、增删O(1)。

**详细回答：**

| 维度 | 数组 | 链表 |
|------|------|------|
| 内存 | 连续分配 | 非连续分配 |
| 随机访问 | O(1) | O(n) |
| 头部插入/删除 | O(n) | O(1) |
| 尾部插入 | O(1)（动态数组摊销） | O(1)（有尾指针） |
| 缓存友好 | 好（局部性原理） | 差 |
| 大小 | 固定/需扩容 | 动态 |

---

### Q2: 栈和队列的区别？⭐

**简答：**
> 栈是后进先出（LIFO），队列是先进先出（FIFO）。

**详细回答：**

| 维度 | 栈 | 队列 |
|------|-----|------|
| 原则 | LIFO | FIFO |
| 操作 | push/pop | enqueue/dequeue |
| 应用 | 函数调用栈、括号匹配、DFS | 任务队列、BFS、消息队列 |

---

### Q3: 哈希表是什么？解决冲突的方法？⭐⭐

**简答：**
> 哈希表通过哈希函数将key映射到数组下标，实现O(1)的查找。冲突解决方法：链地址法、开放寻址法。

**详细回答：**

**哈希函数：**
将任意长度的输入映射为固定长度的输出。

**冲突解决：**
1. **链地址法**：每个桶存一个链表，冲突的元素放在同一链表
2. **开放寻址法**：冲突时探测下一个空位（线性探测、二次探测、双重哈希）
3. **再哈希法**：使用多个哈希函数

**哈希表的优缺点：**
- 优点：查找、插入、删除都是O(1)
- 缺点：无序、扩容开销、哈希冲突影响性能

## 二、树

### Q4: 二叉搜索树（BST）的特点？⭐⭐

**简答：**
> 左子树所有节点 < 根节点 < 右子树所有节点，中序遍历是有序序列。

**详细回答：**
- 查找：O(logn)（平衡时）
- 插入：O(logn)
- 删除：O(logn)
- 最坏情况：退化为链表，O(n)

---

### Q5: 红黑树是什么？⭐⭐⭐

**简答：**
> 红黑树是自平衡的二叉搜索树，通过颜色标记和旋转操作保持近似平衡。

**详细回答：**

**红黑树五个性质：**
1. 每个节点是红色或黑色
2. 根节点是黑色
3. 叶子节点（NIL）是黑色
4. 红色节点的子节点必须是黑色
5. 从任一节点到其叶子的所有路径包含相同数量的黑色节点

**应用场景：**
- Java的TreeMap、TreeSet
- C++的std::map、std::set
- Linux的进程调度器

## 三、排序算法

### Q6: 常见排序算法的时间复杂度？⭐

**简答：**
> 冒泡/选择/插入：O(n²)；归并/堆排：O(nlogn)；快排平均O(nlogn)最坏O(n²)

**详细回答：**

| 算法 | 平均 | 最坏 | 最好 | 空间 | 稳定性 |
|------|------|------|------|------|--------|
| 冒泡排序 | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 归并排序 | O(nlogn) | O(nlogn) | O(nlogn) | O(n) | 稳定 |
| 快速排序 | O(nlogn) | O(n²) | O(nlogn) | O(logn) | 不稳定 |
| 堆排序 | O(nlogn) | O(nlogn) | O(nlogn) | O(1) | 不稳定 |

**面试口诀：**
> "快选堆不稳，其余都稳定"

---

### Q7: 快速排序的原理？⭐⭐

**简答：**
> 选一个基准元素，将数组分为两部分（小于基准和大于基准），递归排序两部分。

**详细回答：**
```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    
    return quicksort(left) + middle + quicksort(right)
```

**时间复杂度：**
- 平均：O(nlogn)
- 最坏：O(n²)（已排序数组，每次只分出一个元素）
- 优化：随机选择基准、三数取中法

## 四、算法思想

### Q8: 什么是动态规划？⭐⭐

**简答：**
> 动态规划将大问题分解为小问题，保存子问题的结果避免重复计算。

**详细回答：**

**适用条件：**
1. 最优子结构：大问题的最优解包含小问题的最优解
2. 重叠子问题：子问题会被重复计算
3. 无后效性：当前决策不影响之前的状态

**示例：斐波那契数列**
```python
# 递归（慢，有重复计算）
def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)

# 动态规划（快，保存结果）
def fib_dp(n):
    if n <= 1:
        return n
    dp = [0] * (n+1)
    dp[1] = 1
    for i in range(2, n+1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```

### Q9: 什么是贪心算法？⭐⭐

**简答：**
> 贪心算法每一步都选择当前最优解，期望得到全局最优解。

**详细回答：**

**适用条件：**
1. 贪心选择性质：局部最优能推导全局最优
2. 最优子结构：大问题的最优解包含小问题的最优解

**示例：找零问题**
```python
def coin_change(coins, amount):
    coins.sort(reverse=True)
    count = 0
    for coin in coins:
        while amount >= coin:
            amount -= coin
            count += 1
    return count if amount == 0 else -1
```

**贪心 vs 动态规划：**
- 贪心：每步最优，不一定全局最优
- 动态规划：考虑所有子问题，保证全局最优
