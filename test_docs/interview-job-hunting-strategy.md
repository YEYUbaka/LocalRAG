# 求职策略与时间规划

> 适用对象：大学生（27届及以后）
> 更新时间：2026-06-17

---

## 一、求职时间线

### 大三上学期（9-12月）

**核心任务：打基础**
- 确定求职方向（后端/测开/前端/AI）
- 刷算法题（LeetCode Hot 100）
- 学习计算机基础（网络、操作系统、数据库）
- 准备项目（1-2个可讲的项目）

### 大三下学期（1-6月）

**核心任务：投实习**
- **1-3月**：春招实习投递（大厂提前批）
- **3-5月**：暑期实习面试
- **6-8月**：暑期实习（争取转正）

### 大四上学期（9-12月）

**核心任务：秋招**
- **7-8月**：秋招提前批
- **9-10月**：秋招正式批（最重要的窗口）
- **11-12月**：秋招补录

### 大四下学期（1-6月）

**核心任务：春招补录**
- **2-4月**：春招（秋招没拿到满意offer的机会）
- **5-6月**：毕业答辩、入职准备

## 二、投递渠道

### 主要渠道

| 渠道 | 特点 | 推荐度 |
|------|------|--------|
| Boss直聘 | 响应快，中小厂多 | ⭐⭐⭐ |
| 牛客网 | 面经丰富，校招信息全 | ⭐⭐⭐ |
| 官网投递 | 大厂必投 | ⭐⭐⭐ |
| 内推 | 简历通过率高 | ⭐⭐⭐⭐ |
| 实习僧 | 实习岗位多 | ⭐⭐ |
| 拉勾 | 互联网公司多 | ⭐⭐ |

### 投递策略

**海投 vs 精投：**
- **海投**：适合前期，快速积累面试经验
- **精投**：适合后期，针对目标公司深入准备

**投递顺序建议：**
1. 先投小公司练手
2. 再投中等公司积累经验
3. 最后投目标大厂

## 三、信息收集

### 公司调研要点

1. **公司业务**：主要产品是什么，商业模式是什么
2. **技术栈**：用什么语言、框架
3. **团队规模**：研发团队多大
4. **融资情况**：是否稳定
5. **口碑评价**：看准网、脉脉上的评价

### 岗位JD分析

**关键信息提取：**
- 硬性要求：学历、专业、技能
- 加分项：项目经验、竞赛获奖
- 工作内容：具体做什么
- 薪资范围：心里有底

## 四、面试准备

### 面试前

- [ ] 了解公司背景和业务
- [ ] 复习岗位相关的八股文
- [ ] 准备项目介绍（STAR法则）
- [ ] 准备反问问题
- [ ] 测试设备（摄像头、麦克风、网络）

### 面试中

- 自我介绍1-2分钟
- 项目介绍3-5分钟
- 技术问题逐一回答
- 不会的诚实说"这个我了解不深"
- 最后反问2-3个问题

### 面试后

- 记录面试问题和自己的回答
- 复盘不足之处
- 跟进面试结果（1周后可询问）

## 五、心态调整

### 常见心态问题

**1. 焦虑**
> "别人都有offer了，我还没有"
> 
> 应对：每个人节奏不同，专注自己的准备，不要和别人比。

**2. 自我怀疑**
> "我是不是不够好"
> 
> 应对：面试是双向选择，被拒不代表你不行，可能只是不匹配。

**3. 疲惫**
> "投了好多简历都没回复"
> 
> 应对：求职是持久战，保持规律作息，适当放松。

### 正确心态

- **面试是学习**：每次面试都是一次学习机会
- **被拒是常态**：大厂录取率<5%，被拒很正常
- **过程比结果重要**：准备过程中的成长才是最大的收获

## 六、速记口诀

```
求职三阶段：春招实习 → 秋招 → 春招补录
投递顺序：小公司练手 → 中等公司积累 → 大厂冲刺
面试三步：准备（调研+复习）→ 执行（自信+诚实）→ 复盘（记录+改进）
```
